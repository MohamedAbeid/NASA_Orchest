# Orchest — Health Sensor Station (permanent hosting)

- [x] English, LTR interface tuned for phones and tablets: sensor station + measurement history.
- [x] Installable PWA with a service worker that caches the app shell and works offline.
- [x] Camera face tracking: distance, blinking, squint, gaze drift and the reading font-size test.
- [x] On-device voice analysis: loudness, pitch, jitter, pauses.
- [x] On-device typing analysis: speed, errors, corrections, rhythm regularity.
- [x] Depression indicators from facial expression: frown, brows, smiling, downward gaze, head tilt, flat affect + 0–100 score.
- [x] All analysis on device; no video or audio is sent to any server.
- [x] Measurements stored locally and shown in an offline-capable history.
- [x] Optional sync layer for a separate .NET API (not required by the hosted build).
- [x] Permanent production deployment without an app server or database: https://orbithealth-di4zhcqm.manus.space
